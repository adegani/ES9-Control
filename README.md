# ES9 Control

Applicazione GUI in Python basata su PySide6 (Qt).

## Installazione ed Esecuzione

1. Installa il pacchetto in modalità editabile:
   ```bash
   pip install -e .
   ```

2. Avvia l'applicazione tramite il comando registrato:
   ```bash
   es9-control
   ```

   Oppure eseguendo direttamente il modulo:
   ```bash
   python -m es9_control
   ```
